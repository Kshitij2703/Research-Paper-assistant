WHAT IS THIS PROJECT?
================================================================================
This is an AI-powered web application that helps researchers analyze academic
papers. You upload a PDF, and the AI reads it and helps you understand it
through various analysis tools.


HOW IT WORKS - SIMPLE FLOW
================================================================================

1. USER UPLOADS A PDF PAPER
   ↓
2. SYSTEM EXTRACTS TEXT FROM PDF
   ↓
3. TEXT IS SPLIT INTO SMALL CHUNKS (500 words each)
   ↓
4. EACH CHUNK IS CONVERTED TO A VECTOR (numbers that represent meaning)
   ↓
5. VECTORS ARE STORED IN A DATABASE FOR FAST SEARCHING
   ↓
6. USER CAN NOW USE ANY OF THE 10 ANALYSIS FEATURES


THE 10 FEATURES EXPLAINED
================================================================================

1. 💬 ASK A QUESTION
   - You type a question about the paper
   - System finds relevant parts of the paper
   - AI reads those parts and answers your question
   - Like having a conversation with the paper
   Example: "What is the main contribution?"

2. 🏷️ DOMAIN CLASSIFICATION
   - AI reads the paper and identifies what field it belongs to
   - Tells you: AI/ML, Biology, Physics, Chemistry, etc.
   - Also gives sub-domains
   Example: "Primary Domain: AI/ML, Sub-domains: NLP, Deep Learning"

3. 📝 SUMMARIZE
   - AI reads the entire paper
   - Creates a short summary (500 words or less)
   - Captures main points, methods, and results
   Example: Turns a 20-page paper into 2 paragraphs

4. 🎯 SIMPLIFY ABSTRACT
   - Takes the technical abstract
   - Rewrites it in simple, everyday language
   - Makes it understandable for non-experts
   Example: Turns jargon into plain English

5. 💡 KEY INSIGHTS
   - Extracts the most important information
   - Gives you bullet points:
     • Main contribution
     • Novel approach
     • Key results
     • Limitations
     • Future work
   Example: Quick overview in 5 bullet points

6. 📚 LITERATURE REVIEW
   - AI generates a comprehensive literature review
   - Includes:
     • Overview of research area
     • Key themes and trends
     • Major findings
     • Research gaps
     • Future directions
   Example: Creates a review section for your thesis

7. 🔗 EXTRACT CITATIONS
   - Finds all references in the paper
   - Lists them in a structured format
   - Shows: Authors, Year, Title, Journal
   Example: [1] Smith et al., 2020, "Title", Nature

8. 🔬 PEER REVIEW
   - AI acts like a journal reviewer
   - Gives scores (1-5) for:
     • Novelty
     • Technical quality
     • Clarity
     • Experimental validation
   - Lists strengths and weaknesses
   - Recommends: Accept/Revise/Reject
   Example: Helps you improve before submission

9. ✅ CONSISTENCY CHECK
   - Compares the summary with the original paper
   - Checks if facts are correct
   - Identifies any made-up information (hallucinations)
   - Gives a consistency score (0-100)
   Example: Verifies AI didn't make mistakes

10. 📊 EVALUATION METRICS
    - Uses ROUGE scores (industry standard)
    - Measures summary quality
    - Shows:
      • Precision (how relevant is the summary)
      • Recall (how much is covered)
      • F1-Score (overall quality)
    Example: ROUGE-1: 0.85 (good quality)

TECHNICAL DETAILS (SIMPLIFIED)
================================================================================

WHAT HAPPENS BEHIND THE SCENES:

Step 1: PDF Processing
- PyMuPDF library extracts text from PDF
- Text is cleaned and organized

Step 2: Chunking
- Long text is split into 500-word chunks
- Chunks overlap by 50 words (to keep context)
- Example: 10-page paper = ~45 chunks

Step 3: Vector Embeddings
- Each chunk is converted to a 384-number vector
- These numbers represent the "meaning" of the text
- Uses a model called "all-MiniLM-L6-v2"
- Happens on your computer (no API needed)

Step 4: Vector Database
- All vectors are stored in FAISS (Facebook's search library)
- Allows super-fast searching
- Can find similar chunks in <10 milliseconds

Step 5: Question Answering (RAG)
- When you ask a question:
  1. Question is converted to a vector
  2. FAISS finds 3 most similar chunks
  3. Those chunks are sent to AI (Llama 3.3 70B via Groq)
  4. AI reads chunks and answers your question
  5. Answer streams back word-by-word (like ChatGPT)

Step 6: Other Features
- All other features work similarly
- Send relevant text to AI with specific instructions
- AI generates the requested analysis
- Results displayed in the UI

LIMITATIONS
================================================================================

1. One Paper at a Time
   - Can only analyze one paper per session
   - Need to upload new paper to switch

2. Context Window
   - Very long papers (100+ pages) may be truncated
   - AI can only process ~15,000 characters at once

3. No Persistence
   - Session lost when server restarts
   - No saved history across sessions

4. Single User
   - Only one person can use it at a time
   - No multi-user support

5. Internet Required
   - Needs connection for Groq API
   - Needs connection for arXiv search
